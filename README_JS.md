# Vidstorm Resolver - Pure JavaScript Version

This is the pure JavaScript/Node.js implementation of the Vidstorm resolver.

## Files

- `server.js` - Express server with auto token extraction
- `stream_fetcher.js` - Standalone script to fetch streams
- `player.html` - Web player UI (unchanged)
- `bookmarklet.js` - Browser token extractor (unchanged)

## Installation

```bash
npm install
npx playwright install chromium
```

## Usage

### 1. Start the Server

```bash
npm start
# or
node server.js
```

Server runs on `http://localhost:8080`

### 2. Test API Endpoints

```bash
# Fetch streams for Spider-Man (auto-extracts token)
curl "http://localhost:8080/api/movie/557"

# Use existing token
curl "http://localhost:8080/api/movie/557?token=TWkB6xPDtW-pyk5ryfskpQ"

# Resolve by IMDB ID
curl "http://localhost:8080/api/imdb/tt0145487"

# Get fresh token
curl "http://localhost:8080/api/token?movieId=557"
```

### 3. Use Standalone Fetcher

```bash
# Fetch with auto token extraction
node stream_fetcher.js 557

# Use existing token
node stream_fetcher.js 557 TWkB6xPDtW-pyk5ryfskpQ
```

### 4. Open Web Player

Open `http://localhost:8080/player.html` in your browser.

## How It Works

1. **Server receives request** for movie (e.g., `/api/movie/557`)
2. **Launches headless browser** (Playwright/Chromium)
3. **Visits vidstorm.ru/movie/557** in the browser
4. **Captures the working token** from network requests
5. **Uses that token** to fetch stream URLs from vidstorm API
6. **Returns stream sources** + subtitles + metadata

## Why This Works

Vidstorm tokens are **IP-bound and session-bound**. They can only be generated by a real browser. Server-side token generation (AES encryption) doesn't work because the server lacks browser context.

The headless browser replicates the exact browser environment that vidstorm expects.

## API Response Format

```json
{
  "movie_id": "557",
  "token": "-Uza4--cSnZoFOHijoaGdg",
  "token_source": "browser",
  "sources": [
    {
      "name": "Lithium",
      "url": "https://storrrrrrm.site/stream/.../master.m3u8",
      "type": "hls",
      "language": "English",
      "flag": "us"
    }
  ],
  "subtitles": [
    {
      "label": "English",
      "file": "https://cache.vdrk.site/v2/movie/557/English.vtt"
    }
  ],
  "metadata": {
    "title": "Spider-Man",
    "overview": "...",
    "poster": "https://image.tmdb.org/t/p/w500/..."
  }
}
```

## Dependencies

- express - Web server
- playwright - Headless browser automation
- axios - HTTP requests
- cors - CORS support

## Notes

- First request may take 5-10 seconds (browser startup)
- Tokens expire quickly (use immediately or re-fetch)
- Browser instance is created per request (no reuse)
- Works on Windows, macOS, Linux
